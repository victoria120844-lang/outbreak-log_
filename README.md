# OUTBREAK LOG

좀비 아포칼립스 생존 시뮬레이터. 생존자를 등록하고, 관계를 정하고, 보급품을 채운 뒤 하루씩 굴리면 — 그날 무슨 일이 있었는지가 일지에 쌓입니다.

서버도, 로그인도, 추적도 없습니다. 브라우저에서 전부 돌아가고 기록은 브라우저에만 남습니다.

## 어떻게 노나

1. **생존자 등록** — 이름, 성별, MBTI 4축, 성격 키워드 3개. MBTI는 16개 목록이 아니라 축을 하나씩 골라 조합합니다.
2. **관계 설정** — 두 번째 생존자를 등록하면 자동으로 관계 행이 생깁니다. 신뢰도는 방향마다 따로이고, 한쪽만 바꾸면 `비대칭`이 됩니다.
3. **보급품** — 27종 중에서 직접 고르거나 `무작위 보급`을 굴립니다. 식량·식수 잔여일이 2일 아래로 떨어지면 패널이 경고 상태로 바뀝니다.
4. **하루 진행** — 유지비, 감염, 사건, 관계 변화가 순서대로 계산되고 일지에 기록됩니다. `자동 진행`은 2.5초마다 하루씩 넘깁니다.

같은 **시드**에 같은 조건이면 같은 기록이 나옵니다. 상단의 `SEED` 를 눌러 복사해 공유하면 다른 사람도 같은 하루를 볼 수 있습니다.

## 로컬에서 실행

Node 20 이상이 필요합니다.

```bash
npm install
npm run dev        # 개발 서버
npm test           # 시뮬레이션 엔진 단위 테스트
npm run typecheck  # 타입 검사
npm run build      # dist/ 에 정적 빌드
```

빌드 결과는 순수 정적 파일이라 GitHub Pages, Vercel, 어떤 정적 호스팅에도 그대로 올라갑니다. Vite의 `base`가 `'./'` 라서 저장소 하위 경로에서도 동작합니다.

## 배포

`main` 에 푸시하면 [.github/workflows/deploy.yml](.github/workflows/deploy.yml) 이 타입 검사 → 테스트 → 빌드 후 GitHub Pages로 배포합니다. 저장소 설정에서 Pages 소스를 **GitHub Actions** 로 지정해야 합니다.

포크했다면 두 곳을 바꾸세요.

- [`src/config.ts`](src/config.ts) — 상단 바에 표시되는 핸들, 제목, 설명, 사이트 주소
- [`index.html`](index.html) — Open Graph / Twitter 카드의 절대 URL (정적 파일이라 자동으로 따라가지 않습니다)

## 만들어진 것

Vite + React 18 + TypeScript(strict), Tailwind CSS v3, Zustand. 라우터 없음, 백엔드 없음, 애널리틱스 없음.

시뮬레이션 엔진은 [`src/features/simulation/`](src/features/simulation/) 에 순수 함수로 분리되어 있고 UI를 전혀 모릅니다. 시드 기반 RNG(mulberry32)를 쓰기 때문에 하루를 다시 계산해도 같은 결과가 나옵니다.

설계 규칙과 디자인 토큰은 [CLAUDE.md](CLAUDE.md) 에 정리되어 있습니다.

## 접근성

- 모든 조작 요소는 키보드로 도달 가능하고 2px 포커스 링이 보입니다.
- 토글 그룹은 `aria-pressed`, 신뢰도 슬라이더는 `aria-valuetext` 로 한국어 해석 문장을 읽어줍니다.
- 일지는 새로 추가된 항목만 읽어줍니다.
- `prefers-reduced-motion` 을 켜면 오프닝, 타이핑 효과, 전환이 모두 꺼집니다.
